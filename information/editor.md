# How to update your asset

{% hint style="success" %}
To get real-time updates, we recommend being in our Discord community and checking the individual channels assigned to send updates regarding each asset.
{% endhint %}

{% hint style="info" %}
If after doing an update you receive an error, simply try updating the entire asset (make a backup of your old files), since on multiple occasions, making a bad update could break multiple aspects of the asset.
{% endhint %}

In our community you can obtain all the changelogs and make each patch yourself by re-downloading the asset from Keymaster again.
