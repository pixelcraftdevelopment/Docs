# Work Orders

## Viewing Available Orders

1. Open tablet and navigate to "Orders" section
2. View list of pending, claimed, and completed orders
3. Review details: customer name, vehicle plate, requested mods
4. Check total price and modification categories
5. Use sorting options: date, status, or customer

![Work Orders List](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/1.png)

## Claiming an Order

1. Find a pending order in the list
2. Click order to view full details
3. Look for "Claim Order" button
4. Click to claim order for yourself
5. Order status changes to "Claimed"

> **Note:** Permission restrictions may apply based on your role.

![Claiming Order](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/2.png)

## Preparing to Fulfill Order

1. Ensure you have claimed order with categories (repair, respray, wheels)
2. Connect to customer's vehicle using tablet
3. Verify vehicle plate matches the order
4. Open order details to see installation categories
5. Prepare for installation minigame

![Order Details](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/3.png)

## Installing Order Categories

1. In order details, click "Install" for category (e.g., "Install Wheels")
2. Minigame appears (prop-based or respray-specific)
3. Complete minigame successfully
4. Modifications applied to vehicle
5. Category marked as installed
6. Repeat for all categories in order

> **Warning:** Failed minigame = no installation. Must retry.

![Installation Process](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/4.png)

![Installation Minigame](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/5.png)

## Completing Orders

1. After all categories installed, locate "Complete Order" button
2. Click to finalize the order
3. Customer notified to pick up vehicle
4. Feedback prompt may appear for customer rating
5. Order moves to "Completed" status

![Order Completion](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/6.png)

## Canceling/Deleting Orders

1. Open order you want to cancel
2. Look for "Delete" or "Cancel Order" option
3. Confirm cancellation
4. Order removed from system
5. Customer may be refunded (depends on config)

![Cancel Order](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/WorkOrders/7.png)
