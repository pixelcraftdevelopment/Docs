# Nitrous System

## Viewing Nitrous Information

**How to access nitrous information:**

1. Connect to vehicle using tablet
2. Click the Nitrous tab to open the nitrous modal
3. View information including:
   - Number of installed nitrous bottles
   - Number of filled bottles
   - Current nitrous capacity per bottle
   - Total available nitrous

![Nitrous Tab](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/Nitrous/1.png)

## Installing Nitrous

**How to install nitrous system:**

1. Obtain nitrous install kit item from shop/stash
2. Open the nitrous modal on your tablet
3. Press the "Install" button
4. Complete the minigame successfully
5. Nitrous system is now installed on the vehicle

![Installing Nitrous](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/Nitrous/2.png)

![Nitrous Installation Minigame](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/Nitrous/3.png)

## Refilling Nitrous Bottles

**How to refill or install new bottles:**

1. Obtain nitrous bottle items from shop/stash
2. Open the nitrous modal on your tablet
3. Press the "Refill" button
4. Wait for 10 seconds for the refill process to complete
5. Bottles are now refilled and ready to use

**Refill options (configurable):**

- **Refill all at once:** All empty bottles refilled simultaneously
- **Refill one by one:** Refill bottles individually
- **Empty refill only:** Only refill when bottles are completely empty
- **Partial refill:** Allow refilling partially used bottles

![Refilling Nitrous Bottles](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/Nitrous/4.png)

![Refill Progress](https://raw.githubusercontent.com/pixelcraftdevelopment/Guides/main/MechanicGuide/images/Nitrous/5.png)

## Using Nitrous

1. Ensure vehicle has filled nitrous bottles
2. Use configured keybind to activate nitrous
3. Vehicle receives temporary speed boost
4. Nitrous capacity decreases during use
5. Refill when capacity runs low
