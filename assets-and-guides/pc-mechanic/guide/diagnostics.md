# Diagnostics

## Vehicle Inspection Overview

1. Connect to vehicle using tablet
2. Navigate to "Inspection" or "Diagnostics"
3. System loads vehicle health data
4. View overall vehicle condition
5. Check servicing status and degradation

## Checking Mileage

1. In connected vehicle panel, locate mileage display
2. Note current mileage value
3. Check unit (km or miles based on config)
4. Compare to service intervals if configured

## Servicing and Degradation

1. View servicing data for connected vehicle
2. Check degradation levels for components
3. Identify parts needing servicing/replacement
4. Schedule or perform servicing as needed
5. Data tracked per vehicle and owner

> **Info:** Tracks wear and tear based on usage and mileage.

## Nitrous System Status

1. View nitrous data in connected vehicle panel
2. Check installed nitrous bottles count
3. See filled bottles and active capacity
4. Refill or install nitrous as needed
5. Data synchronized via statebag system

## Diagnostic Snapshots

1. System auto-creates snapshot when connecting to vehicle
2. Snapshots capture servicing data at that moment
3. Use to track changes over time
4. Compare current state to previous inspections
