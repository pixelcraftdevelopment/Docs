# External Compatibility

## Supported Frameworks

- **QBCore** — Full support with auto-detection
- **Qbox** — Complete compatibility
- **ESX** — Full integration support

> **Note:** Framework is auto-detected by default, or can be manually configured in config.

## Inventory Systems

- **ox_inventory** — Fully integrated
- **qb-inventory** — Full support
- **qs-inventory** — Compatible
- **codem-inventory** — Supported
- **tgiann-inventory** — Integrated
- **esx_inventory** — Framework default

> **Info:** Auto-detects which inventory system is running.

## UI & Notification Scripts

**Notifications:**

**Text UI / DrawText:**

**Progress Bars:**

- qb-skillbar

## Target & Menu Systems

- **ox_target** — Primary target system support

**Menu System:**

## Banking / Society Systems

- **okokBanking** — Full integration
- **fd_banking** — Supported
- **tgg-banking** — Compatible

- **qb-banking** — QBCore v2+ support
