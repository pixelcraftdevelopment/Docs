# Advanced Features

## Stance/Suspension Adjustment

1. Connect to vehicle, open customization menu
2. Navigate to "Stance" category
3. Toggle stance on/off to enable custom suspension
4. Choose "All Wheels" or "Individual Wheels" mode
5. Use sliders: front-left, front-right, rear-left, rear-right
6. Preview changes in real-time on vehicle

> **Info:** Uses statebag syncing for multiplayer consistency.

## Lighting — Xenon Headlights

1. Open "Headlights" or "Xenons" category
2. Toggle xenon headlights on/off
3. Select xenon color from preset options
4. Preview headlight color on vehicle
5. Apply changes

## Lighting — Underglow/Neon

1. Navigate to "Neon" or "Underglow" category
2. Toggle neon lights on/off
3. Choose sides to enable: Left, Right, Front, Back
4. Select neon color using RGB picker
5. Enable flashing effect if desired
6. Apply and preview underglow effects

> **Note:** Uses HSV color space for smooth transitions.

## Tire Smoke Color

1. Open "Tire Smoke" category
2. Enable tire smoke effect
3. Choose smoke color from palette or RGB
4. Preview by spinning wheels (burnout)
5. Apply smoke color

## Vehicle Extras

1. Navigate to "Extras" category
2. View list of available extras for vehicle
3. Toggle each extra on/off individually
4. Preview changes immediately
5. Examples: roof racks, spoilers, etc.

## Bulletproof Tires

1. Find "Bulletproof Tires" in Wheels/Performance
2. Toggle bulletproof tires on/off
3. Test by shooting tires — should not deflate
4. Useful for security vehicles or roleplay
