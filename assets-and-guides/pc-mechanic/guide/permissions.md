# Permissions & Roles

## Available Roles

The script has built-in role system for mechanic employees:

- **Owner:** Full access to all features
- **Manager:** Can manage employees, funds, settings, orders, invoices
- **Mechanic:** Can access shops/stashes, fulfill orders, create invoices
- **Employee:** Basic access — limited permissions

## Manager Permissions

1. Access management panel
2. Deposit/Withdraw shop funds
3. Hire/fire employees
4. Modify employee roles
5. Configure shop settings
6. View all orders and invoices

## Mechanic Permissions

1. Access shops and stashes
2. Purchase parts from shop
3. Assign and fulfill work orders
4. Create and send invoices to customers
5. Connect to vehicles for inspection/servicing
6. Use tablet for diagnostics

## Employee Permissions

1. View work orders (limited)
2. Access basic stash features
3. Cannot manage funds or settings
4. Cannot hire/fire employees
5. May have restricted shop access
