# Core Framework

* **Purpose:** Indicates the core framework used by your server. This should only be changed by customers with custom framework names for their qbcore servers.
* **Options:**
  * 'qb-core: For the qb-core and QBOX framework.
  * 'ESX': For the ESX framework.
*   **Example for custom frameworks:**

    ```
    Config.Core = 'fc-core'
    ```
