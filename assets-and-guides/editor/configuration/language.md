# Language

* **Purpose:** Sets the default language for the resource's user interface.
*   **Supported Languages:**

    * 'en': English (Default)
    * 'pt': Portuguese
    * 'fr': French
    * 'ar': Arabic
    * 'cz': Czech
    * 'da': Danish
    * 'ge': German
    * 'es': Spanish
    * 'ru': Russian
    * 'mn': Mandarin
    * 'it': Italian
    * 'id': Indonesian
    * 'ko': Korean
    * 'pl': Polish
    * 'sv': Swedish
    * 'tr': Turkish
    * 'vi': Vietnamese
    * 'yue': Cantonese
    * 'ja': Japanese



    **Example:**

    ```
    Config.Language = 'fr'  -- Sets the language to French
    ```
