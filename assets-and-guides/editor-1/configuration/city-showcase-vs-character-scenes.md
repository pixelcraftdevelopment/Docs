# City Showcase vs Character Scenes

* | Aspect            | Character Scenes              | City Showcase               |
  | ----------------- | ----------------------------- | --------------------------- |
  | Purpose           | Show character in environment | Show city locations         |
  | Player visibility | Visible as character          | Hidden below ground         |
  | Asset loading     | Small radius around character | Large radius for city views |
  | Camera focus      | Usually on character          | On city landmarks           |
  | Typical FOV       | 20-50 (close shots)           | 45-70 (wide shots)          |
  | DOF strength      | High (0.8-0.95)               | Medium (0.4-0.6)            |
